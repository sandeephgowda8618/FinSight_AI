Baseline date: 2026-10-19  
Authority: original SRS remains authoritative. This matrix records links and observed evidence; it does not change requirements or authorize scope.  
Sources: original SRS; detailed 72-story Jira backlog; four-sprint plan; Sprint 1 test-plan management inventory; current implementation records; read-only live Jira lookup.

## Coverage and audit results

- Source extraction found 399 FR/NFR IDs and 10 data-integrity rules (DIR). All 409 are represented below and in [traceability-requirements.csv](traceability-requirements.csv).
- The source catalog has 72 distinct story aliases. All 72 map to Jira keys confirmed through a read-only live Jira query on 2026-10-19. The Jira project query also returned FIN-84 through FIN-87 without an FS alias in their descriptions; they are not assigned to source catalog items here.
- 328/409 SRS rows have a mapped source-story reference, combining explicit Jira description references with the Sprint 1 test-plan traceability links; 81 have no reference in either source and are marked NOT ASSESSED. 104/409 have a linked supplied Sprint 1 test (direct requirement reference or story link); 305 have no linked test in this 54-case inventory.
- The source management register defines 54 Sprint 1 test cases. The execution record has 52 explicit rows; TC_ENV_001 and TC_ENV_002 have no execution row and retain the source plan default NOT RUN. Other test execution states are copied from the record.
- Requirement implementation status counts: NOT ASSESSED: 110; IMPLEMENTED — VERIFIED: 6; NOT IMPLEMENTED: 45; PARTIAL: 15; PLANNED: 233. VERIFIED appears only where code and evidence support the stated requirement slice. Test execution is separate.
- The four-sprint plan preserves FS-07-04 and FS-08-04 as Release 2 only. No trading feature/schema is classified as Release 1.

## Status conventions

| Field | Meaning |
|---|---|
| SRS reference | PDF page and SRS page/domain section shown in each row. |
| Story alias / Jira | Source alias and verified live Jira issue key. Unmapped rows receive no guessed key. |
| Acceptance criterion | Concise source criterion where recoverable; otherwise a pointer to the linked Jira issue or explicit missing mapping. |
| Implementation status | IMPLEMENTED — VERIFIED, PARTIAL, PLANNED, NOT IMPLEMENTED, BLOCKED, or NOT ASSESSED. |
| Test execution | Independent status per linked test: PASS, FAIL, BLOCKED, or NOT RUN. Missing execution rows use the original plan default and are identified above. |
| Evidence/gap | Repository path or explicit missing evidence/dependency. |
